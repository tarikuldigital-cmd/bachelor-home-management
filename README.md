## ✨ ফিচার

**পাবলিক হোম পেজ (লগইন ছাড়া সবাই দেখবে)**
- মাসের মোট মিল, মোট বাজার খরচ, চলতি মিল রেট, মেম্বার সংখ্যা
- আজকের ও আগামীকালের মেনু, প্রতিদিনের মিলের চার্ট, বাজার ডিউটির তালিকা, এই মাসের বাজারের তালিকা
- যেকোনো মাস বেছে আগের হিসাব দেখা

**মেম্বার প্রোফাইল (প্রত্যেকের আলাদা লগইন)**
- ম্যানেজার প্রত্যেক মেম্বারের প্রোফাইল (ছবি, নাম, মোবাইল, রুম, পেশা, NID, জরুরি যোগাযোগ) আর ইউজারনেম/পাসওয়ার্ড বানিয়ে দেবেন
- মেম্বার লগইন করে দেখবেন: কয়টা মিল হয়েছে, মিল রেট, মিল খরচ, মোট জমা, বাজারে কত টাকা খরচ করেছেন, সার্ভিস চার্জে নিজের ভাগ, কত টাকা পাবেন বা দিতে হবে
- ডিউ অ্যালার্ট, নোটিফিকেশন, মাসিক ইনভয়েস (প্রিন্ট বা PDF)
- নিজের ছবি, মোবাইল নম্বর, ডিফল্ট মিল আর পাসওয়ার্ড নিজেই বদলাতে পারবেন

**সার্ভিস চার্জ (শুধু লগইন করা মেম্বার আর ম্যানেজার দেখবেন)**
- বিদ্যুৎ, ওয়াইফাই, বুয়া, ময়লা, গ্যাস, পানি, বাসা ভাড়া আর অন্যান্য বিল
- সবার মধ্যে সমান ভাগ, অথবা নির্দিষ্ট কয়েকজনের মধ্যে ভাগ
- মিলের জমা আর সার্ভিস চার্জের জমার হিসাব আলাদা থাকে

**Mess Mate-এর মতো ফিচার**
- মিল ট্র্যাকিং: দুইবেলা (দুপুর আর রাত)। Settings থেকে ৩ বেলায় (সকালসহ) বদলানো যায়, প্রতিটা বেলার মানও আলাদা সেট করা যায়, এক ক্লিকে টেমপ্লেট থেকে সবার মিল বসানো
- নির্দিষ্ট সময় পর্যন্ত মেম্বার নিজের আগামীকালের মিল বদলাতে পারেন
- মিল রেট নিজে থেকে হিসাব হয় = মোট বাজার ÷ মোট মিল
- বাজার খরচ, বাজার ডিউটির তালিকা (স্বয়ংক্রিয়ভাবেও বানানো যায়) আর রিমাইন্ডার
- মিলের হিসাব আর সার্ভিস চার্জের হিসাব পুরো আলাদা: আলাদা জমা, আলাদা বকেয়া। একটার টাকা অন্যটায় যোগ হয় না। মেম্বার চলে গেলেও তার পুরনো হিসাব থেকে যায়
- 🔒 মিল, বাজার, জমা আর সার্ভিস চার্জ শুধু ম্যানেজার আপডেট করেন; মেম্বাররা শুধু দেখতে পান
- 🔄 Handover Manager: প্রতি মাসে ম্যানেজার বদল, এখনই অথবা আগামী মাসের ১ তারিখ থেকে (স্বয়ংক্রিয়), হ্যান্ডওভার নোটসহ। নতুন ম্যানেজার সব ম্যানেজার অপশন পান, আগের জন সাধারণ মেম্বার হয়ে যান। মাস অনুযায়ী ম্যানেজারদের তালিকা থাকে
- 📜 মেসের নিয়মকানুন: হোম পেজের নিচে অ্যালার্ট হিসেবে দেখায়, ম্যানেজার Settings থেকে বাংলা আর ইংরেজিতে এডিট করতে পারেন
- 📱 মোবাইল অ্যাপ: Android APK ([এখান থেকে ডাউনলোড](https://github.com/tarikuldigital-cmd/bachelor-home-management/releases/download/app-latest/BachelorHome.apk)), main-এ push করলে নিজে থেকে নতুন APK তৈরি হয়। iPhone-এ Safari থেকে Add to Home Screen করা যায়, অফলাইনেও খোলে
- বাংলা/English, ডার্ক/লাইট থিম, পুরো মোবাইল-ফ্রেন্ডলি, JSON ব্যাকআপ আর রিস্টোর

**SMS গেটওয়ে**
- বকেয়া টাকা পরিশোধের SMS (যাদের ডিউ আছে তাদের বেছে পাঠানো যায়)
- ম্যানেজার আগামীকালের মেনু যোগ করলে বাবুর্চির মোবাইলে SMS যায় (মেনুর সাথে মোট মিলের সংখ্যাও)
- বাজার ডিউটির রিমাইন্ডার, কাস্টম SMS/নোটিশ, SMS লগ
- ডিফল্ট গেটওয়ে BulkSMSBD। অন্য যেকোনো HTTP গেটওয়েও ব্যবহার করা যায়

## 🚀 দুইভাবে চালানো যায়

### ১) ডেমো মোড (GitHub Pages)
সার্ভার লাগে না। ডাটা শুধু ওই ব্রাউজারে থাকে, আর আসল SMS যায় না (তবে ফোনের SMS অ্যাপ খোলার বাটন আছে)।
লগইন: `mehedi / 1234` (ম্যানেজার), `tariqul / 1234` (মেম্বার)। সব মেম্বারের ইউজারনেম তাদের নাম (shuvo, robiul, ashik, kawsar, anik, shakil), পাসওয়ার্ড `1234`

### ২) আসল মোড (নিজের ডোমেইন ও হোস্টিং): সবার ডাটা এক জায়গায় থাকে, আসল SMS যায়
লাগবে Node.js 18 বা তার পরের ভার্সন (cPanel-এর "Setup Node.js App", VPS, Render, Railway ইত্যাদি)।

```bash
git clone https://github.com/tarikuldigital-cmd/bachelor-home-management.git
cd bachelor-home-management
npm --prefix client install
npm run build:server            # VITE_API_URL=same দিয়ে বিল্ড হয়
cp server/.env.example server/.env   # JWT_SECRET, SMS_API_KEY, SMS_SENDER_ID বসান
npm start                       # http://localhost:4000
```
প্রথমবার চালালে `ADMIN_USERNAME / ADMIN_PASSWORD` দিয়ে একটা ম্যানেজার অ্যাকাউন্ট তৈরি হয়। লগইন করেই পাসওয়ার্ড বদলে নিন।
ডাটা থাকে `server/data/db.json` ফাইলে। নিয়মিত Settings → ব্যাকআপ থেকে ডাউনলোড করে রাখুন।

আলাদা API সার্ভার চাইলে ফ্রন্টএন্ড এভাবে বিল্ড করুন: `VITE_API_URL=https://api.yourdomain.com npm --prefix client run build`, তারপর `client/dist` ফোল্ডারটা যেকোনো স্ট্যাটিক হোস্টিংয়ে আপলোড করুন।

### SMS সেটআপ (`server/.env`) — ডিফল্ট গেটওয়ে Muthofun
```
SMS_PROVIDER=muthofun
SMS_API_KEY=Token আপনার_key
```
BulkSMSBD ব্যবহার করলে:
```
SMS_PROVIDER=bulksmsbd
SMS_API_KEY=আপনার_api_key
SMS_SENDER_ID=আপনার_sender_id
```
অন্য গেটওয়ে হলে:
```
SMS_PROVIDER=template
SMS_URL_TEMPLATE=https://gateway.com/send?key=XXX&to={number}&msg={message}
```

## 🧮 হিসাবের নিয়ম
- মিল রেট = মাসের মোট বাজার ÷ সবার মোট মিল
- মেম্বারের মিল খরচ = তার মিল × মিল রেট
- সার্ভিস চার্জের ভাগ = প্রতিটা বিল ÷ যতজনের মধ্যে ভাগ হবে
- মিল ব্যালেন্স = মিল জমা − মিল খরচ, আর সার্ভিস ব্যালেন্স = সার্ভিস জমা − সার্ভিস ভাগ
- নেট ব্যালেন্স পজিটিভ হলে মেম্বার টাকা পাবেন, নেগেটিভ হলে দিতে হবে
